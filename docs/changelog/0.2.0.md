# Synly v0.2.0

输入控制迎来完整支持:macOS 授权流程与按住拦截设置, Windows 未签名版本也能使用输入控制, 并统一了各平台的发布构建.

## Highlights

- 输入控制增强: macOS 首次启用时会引导授予辅助功能权限, 授权后输入后端自动重启生效, 无需重启应用.
- 新增"按住按键或鼠标按钮时不切换设备"选项: 开启后按住按键或鼠标按钮拖动到屏幕边缘不会切换设备, 切出与切回都由鼠标当前所在设备的设置决定.
- Windows 输入控制不再要求 Authenticode 签名, 未签名发布版本也可使用, 同时保留管道与进程身份校验.
- macOS 窗口关闭到托盘时隐藏 dock 图标, 重新显示窗口时恢复.
- 统一发布构建: 使用 `just dist` 生成当前平台的发布产物到 `dist/`, 修复 Linux 构建依赖与 macOS CI runner.
- Windows 应用图标去除白色边角.

## Upgrade Notes

- 按住拦截开关默认关闭, 现有拖拽跨屏行为不变; 需要在 `[input]` 或设置界面中手动开启.
- Windows 未签名版本请仅从可信来源获取, 避免在其他用户可写目录中运行.
