# Synly v0.12.2

Date: 2026-09-29

本版本调整 Android 端发送剪贴板的方式: 不再在剪贴板内容变化时自动读取并发送, 改为只由 user 主动触发. 配置与协议与 v0.12.1 兼容, 不必成对升级.

## Highlights

- Android: 发送剪贴板一律由 user 主动触发, 首页的快速发送按钮与通知栏上的发送操作都能读取当前剪贴板并立即同步到桌面端.
- Android: 不再需要"显示在其他应用上层"权限, 后台不会再弹出透明的读取界面抢占前台焦点.
- Android: 复制内容或切换应用时不会再被自动读取剪贴板打断.

## Breaking Changes

- Android: 剪贴板内容变化不再自动同步到桌面端, 复制之后需要手动发送一次. 迁移方式: 点击首页的快速发送按钮, 或使用通知栏上的发送操作.

## Upgrade Notes

1. 升级前不需要额外备份, 配置, 受信设备与身份密钥都在数据目录里.
2. 升级后可以在系统设置里撤销之前授予的"显示在其他应用上层"权限, 应用已不再申请它.
3. 验证升级成功的方法: About 页显示 `v0.12.2`.

## Bug Fixes

- Android: 之前前台服务监听剪贴板变化, 一变就启动透明界面抢占焦点读取, 会在 user 没有发送意图时反复打断前台应用. 现在监听器与整条自动读取路径都已移除.
- Android: 之前会话刚进入已连接状态时会把当前剪贴板直接发出去, 这条隐式发送也已去掉.
- Android: 移除不再使用的 SYSTEM_ALERT_WINDOW 权限声明.

## Deprecations

- Android: 手动路径不再需要内容去重, ClipboardPayload 的签名计算与 ClipboardReadGate 触发门控随自动路径一并删除.
