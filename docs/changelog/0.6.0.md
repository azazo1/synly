# Synly v0.6.0

本次发布让 Windows 端可以直接控制 UAC 和锁屏界面下的输入, Android 端补充手动剪贴板发送与更稳定的后台服务, 并同步升级协议版本.

## Highlights

- Windows SYSTEM 输入服务: 新增 SynlyInputService (LocalSystem) 隐藏入口, 按需以 SYSTEM 权限启动输入 agent, 通过 `synly service install/uninstall/status` 与设置页管理.
- UAC 与锁屏输入控制: 服务可用时优先使用 SYSTEM agent, 拒绝安装时回退传统 UAC agent; 注入逻辑跟随 Winlogon 安全桌面, 并保持边界返回与光标钳制稳定.
- 服务自愈: 检测到注册的 binPath 与当前 exe 不一致时, 通过一次提权重新配置并重启服务, 避免程序移动后失效.
- 快速退出: 权限监控任务随应用退出及时中止, 托盘与退出按钮不再等待超时.
- Android 手动剪贴板: 通知栏新增发送剪贴板操作, 首页新增快速发送按钮, 按需读取当前剪贴板并反馈结果.
- Android 服务保活: 前台保持剪贴板自动同步, 移除后台 logcat 检测, 任务移除或意外断开后同步服务继续运行, 可从入口恢复连接.

## Upgrade Notes

- 协议版本升级到 21, 本次版本与 v0.5.1 及更早版本不再互通, 请将各设备同步升级.
- Windows 首次使用 UAC 或锁屏控制时会请求一次管理员权限安装服务, 拒绝后回退到旧版 UAC agent 流程.
- Android 不再使用 READ_LOGS 权限, 后台剪贴板自动同步改为前台监听, 手动发送不受影响.
