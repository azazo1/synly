# Synly v0.8.0

Date: 2026-08-05

本次发布新增 macOS 与 Windows 之间的原生滚动换算, 提供可交互的输入 mock 网格用于对比手感, 并修复多项输入同步与 GUI 体验问题.

## Highlights

- 原生滚动: macOS 与 Windows 双向新增原生滚动开关, macOS -> Windows 会去掉平台自带加速度, Windows -> macOS 使用固定 macOS 风格曲线.
- 输入 mock: mock 界面可直接勾选原生滚动和平滑滚动显示, 通过 48px 网格观察滚动方向和位移.
- 配置迁移: config.toml 升级到格式版本 2, 旧配置启动时自动补齐原生滚动字段.
- 输入稳定性: 修复 macOS Spaces 切换时光标重新显示, 扩展鼠标按钮穿透, Secure Input 暂停等场景.
- GUI 日志: 日志页支持自动滚动与滚动到底部, 同步设置面板改为自动高度.

## Features

- 配置: 新增 `native_scroll_macos_to_windows` 与 `native_scroll_windows_to_macos`, GUI 输入设置中可直接开关, 修改后自动重启输入任务.
- Mock: `input-screen-mock` 移除原生滚动 CLI 参数, 改为界面复选框; 网格按事件数固定移动少量像素, 平滑滚动只影响显示层.
- GUI: 日志自动滚动, 滚动到底部按钮, 同步页自动高度与原生滚动 hover hint.

## Bug Fixes

- macOS: 修复 Spaces 切换后光标重新显示, 扩展鼠标按钮在边缘切换时穿透, Secure Input 启用/恢复后输入同步中断的问题.
- macOS -> Windows: 不再把平台已经加速的滚轮增量直接放大, 普通滚轮按事件数折算, 触控板单事件最多折算 1 档.
- Windows: 手动卸载输入服务后不再反复自动申请重装.
- GUI: 输入设置面板不再因新增开关超高溢出.

## Upgrade Notes

- config.toml 从版本 1 自动迁移到版本 2, 无需手动修改.
- 如果你在脚本中使用了 `input-screen-mock --native-scroll-*`, 需要改为在 mock 界面勾选对应复选框.
- 原生滚动默认关闭, 保持原有直通行为; 需要 macOS 原生手感的 Windows -> macOS 方向请手动开启.
