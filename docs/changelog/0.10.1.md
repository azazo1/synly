# Synly v0.10.1

Date: 2026-09-20

本版本把 GitHub Release 和 `just dist` 的播放后端换成 SDL2, 并把运行库打进安装包. 音频协议与 v0.10.0 兼容, 不必成对升级. Android 端仍不传输音频.

## Highlights

- 发布包播放: Windows, macOS 和 Linux 安装包启用 `sdl2-audio`, 随附 SDL2 运行库, 普通用户不必再装开发库.
- Linux: 发布包可以播放对端系统声音; 本机系统采集和输入同步仍不可用.
- 源码开发: 日常 `cargo run` / `just debug` 仍使用 WASAPI 或 AudioQueue, 不要求本机安装 SDL2.

## Upgrade Notes

1. 从 v0.10.0 升级不需要改配置, 也不需要两端同时升级. 音频 UDP 仍是 v0.10.0 的 v2 协议, 与 v0.9.1 仍然不互通.
2. 覆盖安装发布包即可. macOS Homebrew 的 sdl2-compat 还会在应用包内带上 SDL3; Windows zip 带 `SDL2.dll`; Linux tar 带 `libSDL2-2.0.so.0`.
3. 验证升级成功的方法: About 页显示 `v0.10.1`; 接收端能听到发送端系统声音.

## Features

- 打包: `just dist` 和发布 CI 启用 SDL2 播放, 并把 SDL2 (以及 macOS sdl2-compat 需要的 SDL3) 复制进安装包, 同时随附 zlib 许可全文.
- Linux: 发布包设置 `$ORIGIN` rpath 并携带 SDL2, 可以播放对端音频.
