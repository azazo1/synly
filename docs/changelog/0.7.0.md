# Synly v0.7.0

Date: 2026-08-04

本次发布为所有配置目录引入版本号与自动迁移, 将 GUI 窗口状态拆分为独立文件, Android 端增加手动重连并优化前台通知展示.

## Highlights

- 配置版本化: config.toml, identity.toml, trusted-devices.toml 和新增的 gui-state.toml 都带有独立 version 字段, 旧格式会在启动时自动迁移.
- GUI 状态隔离: 首次运行标记和窗口尺寸从 config.toml 移入 gui-state.toml, 窗口位置变化不再重写主配置.
- Android 手动重连: 已连接状态卡片支持点击强制重连, 即使关闭自动重连也可使用上次目标设备.
- Android 通知刷新: 前台通知每 60 秒更新时间戳, 保持通知栏排序靠前且不重复提醒.

## Features

- 配置: 未带版本号的旧配置文件会被迁移到当前版本, 未来可通过独立 migration 模块按版本顺序升级.
- Android: 手动重连可在不开启自动重连时快速恢复上次目标连接, 通知刷新保持服务状态可见.

## Bug Fixes

- macOS 构建不再出现 Windows-only 死代码警告.
- lnd 从 git 固定引用切换为 crates.io lnd-core 0.1.0, 锁定依赖树并减少外部源码依赖.

## Upgrade Notes

- 旧版无 version 字段的配置文件会在首次启动时自动写入版本号, 无需手动备份.
- 若手动编辑配置文件, 请保留顶层 version 字段; 高于当前版本的配置会被拒绝.
