# Synly v0.5.0

Android 剪贴板扩展为支持文件和相机照片, 新增启动自动重连与快速文件操作, 大小设置支持人类可读单位, 并补齐 Android 生命周期与界面细节.

## Highlights

- Android 文件与相机剪贴板: 通知栏提供发送文件和拍照操作, 系统分享菜单也可以作为发送入口; 文件会缓存并同步到已连接桌面, 接收端保留原始文件名.
- 剪贴板容量控制: 单次发送总量与本地缓存总量分别受设置上限约束, 缓存会按上限自动清理; Android 设置中的图片大小字段拆分为剪贴板大小和缓存大小.
- 启动自动重连: Android 设置新增开关, 开启后应用启动时自动连接上次目标并启动前台同步服务; 关闭后仍可手动连接, 从最近任务移除应用时会停止服务和通知.
- 快速文件操作: Android 首页新增发送文件和拍照按钮, 设置页新增缓存清理入口并提供结果反馈.
- 可读大小输入: 桌面端和 Android 设置均可输入并预览 100 MiB, 512 MiB 等人类可读大小, 桌面端保存失败时会在界面显示错误信息.
- Android 界面与体验: LAN 扫描结果保留在设备卡片内, 剪贴板文件读取改为异步生命周期, 文件发送后不再显示临时前缀.

## Upgrade Notes

- Android 设置中原图片大小字段不再使用, 改为剪贴板大小和缓存大小; 旧偏好会回退到新的默认值 (100 MiB / 512 MiB).
- 本次未修改协议版本, 与 v0.4.0 设备可继续互通.
