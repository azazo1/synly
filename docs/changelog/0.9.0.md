# Synly v0.9.0

Date: 2026-09-10

本版本为桌面端引入内置自动更新, 修复 macOS 幽灵键导致的边缘切换阻塞, 并让断连后的重连更快恢复. 使用 `input-screen-mock` 或 `just install` 的用户请先阅读 Breaking Changes 与 Upgrade Notes.

## Highlights

- 自动更新: 桌面端可以从 GitHub Release 检查并下载更新, 校验 SHA256, 支持断点续传, 取消和跳过版本, 下载完成后按平台执行安装并重启.
- 输入稳定性: 修复 macOS 幽灵键长时间阻塞边缘切换的问题, 新增控制端应用事件过滤开关并默认开启, 按键映射扩展到 F13-F24.
- 快速重连: 会话断开后优先直连上次对端地址, 数秒内恢复时不再弹出断连通知.
- 配置迁移: config.toml 升级到格式版本 4, 新增 `[update]` 段和 macOS 隐藏窗口时同时隐藏 Dock 图标的选项.
- 发布流程: 分支, PR, tag 和手动触发统一编译打包并上传 Actions artifact, 版本号由 `scripts/build-version.sh` 从 git 计算后注入二进制.

## Breaking Changes

- `input-screen-mock` 移除了 `--edge`, `--hotkey`, `--width` 和 `--height` 参数. 迁移方式: 在 mock 窗口的设置页中调整对应选项, 命令行只需执行 `just input-screen-mock`.
- justfile 移除了 `install` recipe. 迁移方式: 使用 `just dist` 生成当前平台的分发产物, 或自行执行 `cargo install --path .`.

## Upgrade Notes

1. config.toml 会从版本 2 或 3 自动迁移到版本 4, 无需手动修改; 手工编辑配置时请保留顶层 `version` 字段.
2. 自动更新只处理本机平台对应的产物: macOS 使用 dmg, Windows 使用 zip, Linux 使用 tar.gz. 便携版和安装版都适用.
3. 自动检查更新默认开启, 可以在设置页或托盘菜单中关闭, 也可以跳过某个具体版本.
4. 验证升级成功的方法: 启动后 About 页显示的版本号应为 `v0.9.0`, 日志文件首行会记录本次启动的版本与日志路径.

## Features

- 更新: About 页与托盘菜单都可以手动检查更新, 显示下载进度与校验结果, 失败时可以重试或打开 Release 页面; 请求跟随系统代理设置.
- 更新: 支持取消进行中的下载, 取消后已下载部分会保留以便续传, 安装过程中不允许取消.
- 输入: 新增 `reverse_mouse_wheel` 与 `reverse_trackpad` 的 GUI 开关, 两个方向设置都可以在界面中修改并自动重启输入任务.
- 输入: 新增 `filter_app_events` 开关, 仅控制端生效, 过滤非 HID 来源的合成按键和鼠标事件.
- 输入: 按键映射支持 F13 到 F24, 在 macOS 与 Windows 之间使用扩展 HID usage.
- 输入: `input-screen-mock` 的设置改为窗口内驱动, 可以调整边缘, 热键, 尺寸, 原生滚动和反向滚动, 并显示本机与对端的按下状态.
- 连接: Join 会话会用已发现的对端地址直接连接, 同时竞速多个候选地址, 缓存地址失败后才回退到发现流程.
- 连接: 自动重连先做若干次快速直连重试, 再进入常规退避; 五秒内恢复的会话不再发送断连与重连通知.
- 桌面: 托盘菜单新增检查更新和自动检查开关, 左键单击托盘图标会显示并聚焦主窗口.
- 桌面: macOS 可以设置隐藏主窗口时是否同时隐藏 Dock 图标.
- 桌面: 新增 `just debug` 隔离调试实例, 数据目录和日志都落在 `target/synly-debug/`; `just fake-dist` 生成版本固定为 `v0.0.0` 的自动更新测试产物.
- Android: 连接成功后清除上一次失败留下的错误提示.

## Bug Fixes

- macOS: 修复幽灵键长期阻塞边缘切换, 普通按键在系统侧残留时也能正确清理, 同时补全 F13-F24 的键码映射.
- macOS: 不再替换 winit 的 NSApplication delegate, 避免 Dock 与激活行为异常.
- 输入: 原生滚动只处理普通鼠标滚轮, 触控板保持直通; Windows 通过事件附加信息区分触控板.
- 桌面: GUI 回调中的 panic 不再终止整个进程, 出错时记录回调名与 panic 内容并保持界面存活.
- 桌面: 日志初始化提前到配置加载之前, 启动失败现在会记录到日志文件, 而不是静默退出.
- 更新: 取消下载后, 被取消的任务不会覆盖更新的状态; 系统代理变化后更新请求会重新建立连接.
- 打包: `package-linux.sh` 与 `package-macos.sh` 在显式传入版本, target 和输出目录时会正确回退到 `target/release` 下的二进制.
- Android: 重连成功后不再保留上一次的错误文案.

## Performance

- CI: Rust 依赖与 target 目录, 以及 Gradle User Home 与构建状态都会缓存, 减少重复构建时间.
