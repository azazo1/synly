# Synly v0.11.0

Date: 2026-09-20

本版本把 Windows 与 Linux 的发布形态改成安装包, 自动更新交给平台安装器完成, 因此新版本新增或移除的程序文件 (例如随附的 dll) 都能正确落地. 解压即用的旧版无法自动跨到本版本, 升级前请先看 Upgrade Notes. 音频与输入协议与 v0.10.1 兼容, 不必成对升级.

## Highlights

- Windows 发布 `-setup.exe` 安装器, 按当前用户装到 `%LOCALAPPDATA%\Programs\Synly`, 全程不需要管理员权限, 卸载项与快捷方式由安装器维护.
- Linux 发布 `-setup.tar.gz`, 内含 `install.sh`, 把程序装到 `~/.local/opt/synly` 并建立 `~/.local/bin` 入口, 全程不需要 root.
- 自动更新改为交接平台安装器: 下载校验完成只到 "已就绪", 点 "重启并更新" 后才运行安装器整目录替换, 下次启动回显落地结果.
- 快捷开关里的接收声道切换后立即安全重连生效.

## Breaking Changes

- 发布形态由便携归档改为安装包, 更新资产名随之改变. 仍在解压目录里运行的旧版 (Windows zip, Linux tar.gz) 无法自动更新到本版本, 必须手动安装一次安装包. 迁移方式见 Upgrade Notes.

## Upgrade Notes

1. 升级前先退出正在运行的旧实例 (Windows 从托盘退出, Linux 结束进程). 配置, 受信设备与身份密钥都在数据目录里, 不需要额外备份, 安装与卸载也不会触碰它.
2. Windows 运行 `synly-0.11.0-windows-<arch>-setup.exe`; Linux 解包 `synly-0.11.0-linux-<arch>-setup.tar.gz` 后执行 `./install.sh --silent`. 确认新入口 (Windows 开始菜单, Linux `~/.local/bin/synly`) 启动正常后, 再删除旧的解包目录.
3. 验证升级成功的方法: About 页显示 `v0.11.0`; 之后检查到新版本时, 安装落地后状态栏会提示 "已更新到 vX".

## Features

- 更新: 安装版由平台安装器整目录落地, 新版本新增的 dll 与资源会被补齐, 被移除的文件会被清理. 程序文件被占用 (例如 Windows 输入服务仍在运行) 时先让位再写入, 不再因为占用而升级失败, 安装没有走完时旧文件会恢复回去.
- Windows: 更新落地后的首次输入提权会用一次 UAC 重启输入服务, 让它加载新版本.
- 快捷开关: 接收声道 (立体声 / 5.1 / 7.1) 切换后立即重连生效, 卡片上原本的 "下次连接时生效" 提示已移除.

## Bug Fixes

- 会话: 连接方 (join) 在设备列表里点 "断开" 现在会结束当前会话, 不再只有 "断开全部" 生效; 撤销对端信任时同样会断开.
- 界面: 修正快捷开关卡片里溢出到面板外的提示文字.
