# Synly v0.4.0

输入控制新增游戏光标模式, 主机活跃会话可跨重连与重启保持, Android 支持配置备份导入, 并补齐输入链路与前台服务稳定性.

## Highlights

- 游戏光标模式: 新增 desktop/auto/game 三态光标模式, game 模式将远端 Motion 以相对增量直接注入, 支持锁定光标并读取相对移动的游戏; auto 模式按系统光标捕获状态自动切换, 捕获结束后继续保留远端控制.
- 活跃会话粘性: host 重启后仍保持首选活跃设备, 首选设备断线后有 30 秒回归保留期, 其他设备可临时接管, 首选设备回归时自动夺回完整能力.
- Android 配置迁移: 支持将设置, 设备身份和可信设备导出为版本化 JSON 文件或剪贴板, 也可从文件或剪贴板导入并立即重载客户端.
- Android 隐私与生命周期: 首页默认以掩码显示最近收到的剪贴板内容并可手动切换; 未连接时不再保持前台服务和常驻通知, 返回键行为与通知点击聚焦同步修正.
- 输入稳定性: Windows 输入代理断线后自动恢复且不再误杀健康代理, 游戏锁定光标时接管不再导致会话失败, macOS 修复 grave 键捕获与映射.
- 调试工具: 新增可交互控制端 mock 和提权接收端 mock, 覆盖键盘捕获, 游戏光标和 Windows 提权注入路径.

## Upgrade Notes

- `config.toml` 的 `[input]` 新增必填字段 `cursor_mode`, 严格 schema 不会自动迁移; 现有配置需要补上 `desktop`, `auto` 或 `game` 三选一.
- 自动游戏光标相关旧字段不再使用, 请通过新的三态 `cursor_mode` 配置.
- 本次未修改协议版本, 与 v0.3.0 设备可继续互通.
