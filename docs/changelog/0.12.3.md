# Synly v0.12.3

Date: 2026-09-29

本版本把 Android 前台同步的自动退出条件从"默认网络是移动数据"改成"没有 Wi-Fi 也没有热点", 让开热点时还能继续局域网同步, 完全没有局域网时也不再空耗连接. 协议与配置与 v0.12.2 兼容, 不必成对升级.

## Highlights

- Android: 判断依据改成有没有 Wi-Fi 与热点, 开着热点时后台同步不会再被误停.
- Android: 完全没有可用局域网 (飞行模式, Wi-Fi 开关打开但没连上任何网络) 时同样在 30 秒后退出.
- Android: 到期前会复核一次, 期间恢复 Wi-Fi 或开热点就取消退出.

## Upgrade Notes

1. 升级前不需要额外备份, 配置, 受信设备与身份密钥都在数据目录里.
2. 退出条件只看有没有 Wi-Fi 与热点, 与移动数据无关: 手机开着 Wi-Fi 开关但没连上任何网络时按没有局域网处理.
3. 通过 VPN 隧道访问桌面端不在判定范围内, `tun` 这类隧道接口不计作局域网, 只走 VPN 时会按没有局域网处理.
4. 验证升级成功的方法: About 页显示 `v0.12.3`.

## Bug Fixes

- Android: 之前读默认网络类型判断是不是移动数据, 而开着热点时手机自身仍然是蜂窝默认网络, 于是热点下后台同步会在 30 秒后被停掉, 明明还能局域网同步. 现在改为判断有没有 Wi-Fi 与热点.
- Android: 之前的退出条件只在默认网络是移动数据时成立, 飞行模式或 Wi-Fi 未连接这类完全没有可用局域网的场景会一直保持连接. 现在没有可用局域网同样会退出.
- Android: 热点不会作为 `TRANSPORT_WIFI` 网络暴露给应用, 所以额外按本机接口判断, 常见热点接口名 (ap, softap, swlan, wlan1) 在还没有客户端接入时也认.
- Android: 蜂窝与隧道接口 (rmnet, ccmni, pdp, wwan, clat, v4-, tun, sit, ip6tnl, dummy) 不计作局域网, 避免运营商级 NAT 地址被误判成局域网而永远不退出.
- Android: Wi-Fi 网络回调注册失败时不再按"没有 Wi-Fi"处理, 避免误停后台同步; 接口枚举也移到 IO 线程, 不在服务主线程上做系统调用.
