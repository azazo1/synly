# Synly v0.11.1

Date: 2026-09-20

本版本修复 macOS 上点 "重启并更新" 后应用不退出, 因而无法覆盖安装包的问题. 音频与输入协议与 v0.11.0 兼容, 不必成对升级.

## Highlights

- macOS: 点 "重启并更新" 后会把替换工作交给脱离进程的脚本并立刻退出, 不再只打开 dmg 而进程还活着.

## Upgrade Notes

1. 从 v0.11.0 升级: Windows 和 Linux 可以继续用应用内自动更新. macOS 上 v0.11.0 的 "重启并更新" 不会退出当前进程, 请先从托盘退出, 再打开本版本 dmg 拖到 `/Applications` 覆盖安装.
2. 覆盖安装不触碰数据目录, 配置和受信设备会保留.
3. 验证升级成功的方法: About 页显示 `v0.11.1`; 之后再有更新时, 点 "重启并更新" 后应用应退出并自动拉起新版本.

## Bug Fixes

- macOS: 已安装的 `.app` 被误判成便携运行, 点 "重启并更新" 只打开 dmg, 本进程不退出, LaunchServices 占着 bundle 导致无法覆盖. 现在只要跑在 `<bundle>/Contents/MacOS/` 里就会交接替换脚本并走统一退出路径.
