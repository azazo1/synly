# Synly v0.3.0

Android 端正式接入同步网络, 主机可以同时连接多台设备, 剪贴板方向改为实时协商, 桌面端与 Android 端共用新的核心库和重连机制.

## Highlights

- Android 应用: 新增 Compose 客户端, 支持剪贴板同步, PIN 配对, 可信设备, mDNS/LND 发现, 前台服务, 应用内日志查看器和实时连接状态显示.
- Android 剪贴板读取改用透明 Activity 获取焦点, 不再依赖无障碍服务轮询, 权限引导和状态提示同步更新.
- 主机多会话: 同一主机可同时保持多个可信或新配对连接, 文件, 音频和输入同步作用于活动会话, 支持在设备列表中切换和单独断开.
- 剪贴板广播: 多设备之间共享剪贴板, 内置回声抑制, 签名去重, 单源限速和出站队列上限, 防止循环广播.
- 剪贴板方向协商: 配对时确定收发方向并写入签名证明, 连接后按实时能力状态生效, 方向调整无需重新配对.
- 统一重连驱动: Android 与桌面端共用指数退避重连逻辑, 支持取消等待, 终端失败和成功会话后重置退避.
- Android 稳定性: 断开后不再自动重连, 重连前按设备 ID 通过 mDNS/LND 重新发现目标, 修复重复配对导致 PIN 刷新和旧地址失效问题.
- CLI 与版本: 新增 host/join 子命令和全局 --headless 参数, CLI --version 与 About 页面自动显示基于最近版本 tag 的构建版本.
- 输入控制: Windows 已提权运行时直接复用令牌启动输入代理, 跨平台水平滚动方向按系统组合规范化, 支持重复按键映射目标.

## Upgrade Notes

- 协议版本已升级到 20 且严格校验, 所有设备需要更新到 v0.3.0 才能互相连接, 旧版本之间不受影响.
- 主机现在可以保持多个连接, 文件, 音频和输入同步只作用于当前活动会话; 连接新设备后如需要切换, 请在设备列表中选择.
- Android 首次使用时按应用内引导授予通知和悬浮窗等权限, 剪贴板读取不再要求无障碍服务权限.
