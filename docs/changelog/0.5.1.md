# Synly v0.5.1

本次发布补全 Android 发布链路, tag 构建会生成并校验签名 APK, GitHub Release 同步附带 APK 下载.

## Highlights

- Android APK 发布: GitHub Release 现在附带 arm64 APK, 并在发布前完成 zip 结构与 apksigner 校验.
- 签名发布: 配置仓库签名 secret 后, tag 发布会自动解码 keystore 并构建 signed release APK; 未配置时 tag 发布会失败.
- 本地构建: `just android-build` 可自动读取 `secrets/synly-signing.env` 构建签名 release APK, 也支持 `just android-build debug` 和 `just android-build release`.

## Upgrade Notes

- 从 GitHub Release 下载的 Android APK 仍需要手动允许安装未知来源应用.
- 本次未修改协议版本, 与 v0.5.0 设备可继续互通.
