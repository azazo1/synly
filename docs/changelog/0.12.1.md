# Synly v0.12.1

Date: 2026-09-28

本版本修复 Android 端重连时端口过期导致的额外等待, 并完善最近连接列表的展示与容错. 配置与协议与 v0.12.0 兼容, 不必成对升级.

## Highlights

- Android: 连接成功后同时记住实际使用的端口, 下次重连直接命中, 不再因为旧的随机端口白等超时再重新发现.
- Android: 最近连接列表显示对侧设备名而不是内部设备 ID, 连接成功后列表立即刷新.
- Android: 配置导入遇到最近连接列表里的无效条目会跳过该项, 不再让整个导入失败.

## Bug Fixes

- Android: 之前只持久化地址不持久化端口. 宿主每次启动绑定的端口会变, 旧端口必然失效, 于是冷启动要付出完整 TCP 超时再按设备 ID 重新发现. 现在把会话实际使用的端口写回目标.
- Android: 最近连接卡片之前直接用设备 ID 当标题, 现在解析为可信设备名, 找不到时退回地址.
- Android: 配置导入不再因为最近连接列表中的一条坏记录放弃整个文件, 逐条解析并跳过无效项.
- 核心: TCP_CONNECT_TIMEOUT 从 10 秒降到 3 秒, 旧端口失效时的等待更短, 恢复更快.

## Upgrade Notes

1. 升级前不需要额外备份, 配置, 受信设备与身份密钥都在数据目录里.
2. Android 上已有的最近连接记录会在下次成功连接后自动补上真实端口, 无需手动处理.
3. 验证升级成功的方法: About 页显示 `v0.12.1`.
